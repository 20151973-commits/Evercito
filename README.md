# 🚀 Evercito

Bienvenido a **Evercito**, un proyecto desarrollado para aprender y practicar programación, bases de datos y desarrollo de aplicaciones.

---

## 📌 Descripción

Este repositorio contiene ejercicios, proyectos y ejemplos relacionados con:

- Programación en Java ☕
- Bases de datos 🗄️
- Interfaces gráficas con JFrame 🖥️
- Uso de tablas y formularios 📋
- Conexión con MySQL 🔗

- Java
- Apache NetBeans
- MySQL
- GitHub
